# WorldBox 国家领袖情报

你正在一个 WorldBox 世界里扮演某个国家的领袖。这个 skill 让你**读取真实游戏数据**，
而不是靠想象来描述局势。

## 谁提供数据

一个外置程序（不是 mod）持续读取 WorldBox 写出的存档与统计库，把世界拆成
"每个国家一份"的中文情报文档，同时开一个本地接口。数据本身来自游戏，**你不需要
也无法直接访问游戏**——只能通过下面两种方式读取。

## 第一步：确认你是哪个国家

你的 system prompt 会告诉你国家的名字。把它记下来，作为 `--me` 参数使用。

```bash
# 列出世界里所有国家（先看清有哪些国家、谁强谁弱）
python <SKILL目录>/scripts/wb.py whoami

# 用你的国名确认身份，拿到你的编号与情报目录
python <SKILL目录>/scripts/wb.py whoami 大仁
```

如果 system prompt 给的名字和列表对不上（比如是简称，或国家已经改名/灭亡），
就用 `whoami` 列出全部国名，挑最接近的那个；仍然不确定时，选择人口与城市数
最符合你 prompt 描述的国家，并在回答里说明你的判断依据。

> 想让命令更短，可以先 `export WB_NATION=大仁`，之后的命令就不必再写 `--me`。

## 第二步：按需要读取情报

```bash
python wb.py brief    --me 大仁   # 极简摘要：决策要用的十几个数字（先看这个）
python wb.py self     --me 大仁   # 完整国情：国王、城市、军队、外交、大事记
python wb.py others   --me 大仁   # 其他国家横向对比 + 战争/立场矩阵
python wb.py history  --me 大仁 --last 10    # 最近 10 年的趋势
python wb.py events   --me 大仁   # 我经历过的大事
python wb.py world                # 世界概览与国力排行
```

加 `--compact` 可以得到单行 JSON，更省 context。

**读数据的顺序很重要。** 不要一上来就读 `self`（它有 15 KB 左右）。
先 `brief` 看清全局，只有当你真的需要某个细节（比如每座城市的人口、历任国王）时，
才去读 `self`。你的 context 是最稀缺的资源。

## 数据长什么样

所有文档的键是固定英文名，值是简体中文，例如：

```json
{
  "identity": { "名称": "大仁", "格言": "Hold my gold", "种族称呼": "辛未人类亚种" },
  "ruler":    { "国王": "吕䎅冥", "国王特质": [{"id": "wise", "label": "睿智"}] },
  "status":   { "是否存续": true, "声望": 1623, "声望排名": 1 },
  "demographics": { "人口": 1767, "含船只条目数": 1784, "成年人口": 1147, "饥饿": 79 },
  "military": { "军队总兵力": 309, "军队支数": 14, "累计击杀": 771 },
  "territory":{ "城市数": 14, "领土地块": 793, "建筑总数": 6863, "首都": "北平" },
  "diplomacy":{ "战争": [...], "对外关系": [{"名称": "莱国", "关系": "交战"}] },
  "history":  [ {"timestamp": 212, "population": 1716, "army": 356, "money": 23034} ]
}
```

字段的完整含义见 `references/数据字典.md`。几个必须记住的口径：

- **人口**指常住人口，**不含船只**（船只单列在 `船只` 字段）。所有文档统一用这个
  口径，所以 `self.json`、`others.json`、`_index.json` 里的人口可以直接互相比。
  如果你需要和存档原始条目数对齐，用 `含船只条目数`。
- **军队总兵力**是"在编军人"人数；和 `history` 里游戏自己统计的 `army` 会有小幅
  差异，因为逐年统计是每年年初记一次，而这里是最新存档的即时值。
- **领土地块**是城市所占地块数之和。
- **存档不记录角色年龄**，所以没有"国王几岁"。只有世代与在位起始年。
- **粮食、国库、忠诚**这类数字只在 `history` 里，城市记录本身不保存它们。

**同一个指标会有两个不同时点的值**，这不是矛盾，别把它当成数据错误：

| 指标 | 即时值 | 历史值 |
|---|---|---|
| 人口 | `demographics.人口` | `history[].population` |
| 军队 | `military.军队总兵力` | `history[].army` |
| 声望 | `status.声望` | `history[].renown` |

游戏每年年初记一次统计，即时值则是当前存档时刻的实况。
**判断"现在多强、现在能打多少"用即时值；判断"在变强还是变弱"用 `history`。**
`self.json` 里的 `knowledge.口径歧义提示` 会把这个国家的两套数字同时列出，
遇到不确定时读它。

⚠️ **两套时间刻度，别混淆**：`world.年份`（如 212）是"历史纪年"，
而 `history` 里的 `timestamp` 和事件里的 `年份`（如 12468）是"世界时间"，
两者起点不同。**只在同一套刻度内部比较**——比如事件之间比先后、
`history` 行之间比趋势。不要拿事件的 `年份` 去减 `world.年份`。

## 数据新鲜度：最重要的一件事

每份文档里都有 `world.存档距今秒数`，表示这份数据是多久以前从游戏里读出来的。

WorldBox 大约每 5 分钟自动存档一次，所以这个数字通常在一两百到三百秒之间，
偶尔会更大（游戏暂停时不会写新存档）。

**超过 600 秒（10 分钟）就说明数据已经过期，游戏多半暂停了或关闭了。**
工具会自动提醒你，你不需要自己去比这个数字：

- 文档里会多出一个 `_警告` 字段（在 `world`、`_index.json` 里都能看到）；
- `wb.py` 会在 **stderr** 上打印一段醒目的过期提示（这样不会污染你读的 JSON）。

看到警告时你应该：
1. 明确告诉使用者"数据可能已过期，最后一次更新是 X 分钟前"；
2. 仍然基于这份数据给建议，但说明它的时效性；
3. 不要假装这是实时战况。

**绝对不要编造数据里没有的数字。** 如果某个数字是 `null`、空列表或字段缺失，
就诚实地说"存档没有记录这一项"，而不是猜一个看起来合理的值。领袖的决策
质量完全取决于情报的真实性。

## 怎么用这些数据做决策

一个领袖真正会问的问题，以及该看哪里：

| 我要判断 | 看哪里 |
|---|---|
| 我还活着吗？ | `status.是否存续`——为 false 说明国家已灭亡 |
| 我打得过谁？ | 我的 `military.军队总兵力` 对比他国的 `军队兵力`，别用人口去猜 |
| 我的人民过得好吗？ | `demographics.饥饿`、`平均幸福度`，以及 `history` 里的 `hungry`/`food` 趋势 |
| 有没有内乱风险？ | `history` 里 `homeless`（无家可归）与 `left`（人口流失）是否在涨 |
| 谁是我的敌人？ | `diplomacy.战争` 与 `diplomacy.敌人`；`others` 里的 `关系矩阵` 看谁在打谁 |
| 国家在变强还是变弱？ | `history` 里 `population`/`army`/`money`/`territory` 的走向，**看趋势不要看单点** |
| 为什么变成这样？ | `recent_events` 与 `events` —— 国王更替、城市被毁、阴谋、战争爆发都在这里 |

**看趋势，不要只看当前一帧。** 一个国家人口从 2800 掉到 1700、国库腰斩、
饥饿人数居高不下——这才是真正决定领袖该做什么的信号，而单看"人口 1767"
什么也说明不了。`history` 是这个世界给你的记忆。

## 性格与决策风格

这个 skill 只提供情报，不规定你该怎么决策——**决策正是你扮演领袖的地方**。
同一个局面，不同的领袖会做不同的事：

- 一个`睿智`而国库空虚的国王，可能选择先修养生息、与强邻和谈；
- 一个`嗜血`且军队占优的国王，可能选择趁对方饥荒时宣战；
- 一个`多疑`的国王，可能因为邻国军队在增长而先发制人。

你的 system prompt 描述的性格与目标，应该体现在你如何使用这些情报上：
同样的数字，不同的领袖会读出不同的含义，做出不同的选择。请在回答里说清
**你依据哪些数据得出这个判断**，这既让决策可追溯，也体现了领袖的思维方式。

## 没有数据时怎么办

如果命令报错说读不到数据：

1. `python wb.py whoami` 会告诉你当前用的是哪个后端（`http` 还是 `file`）；
2. 检查数据服务是否在运行（需要有人先执行 `python worldbox_agent.py serve`）；
3. 如果服务没开，让用户先启动它；同时磁盘上的 `data/` 目录里可能有上次导出的
   快照，`wb.py` 会自动回退到文件读取。

无论哪种情况，都不要因为读不到数据就开始编造局势。告诉用户你需要情报，
并说明怎样才能拿到。

### 输出变成乱码或问号

`wb.py` 启动时已经把控制台切到 UTF-8 并重设了输出编码，正常情况下不需要你做
任何事。如果仍然看到乱码（少数受限终端会出现），手动加一层保险：

```powershell
# PowerShell
$env:PYTHONIOENCODING = "utf-8"; [Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```

```cmd
:: cmd.exe
chcp 65001
```

不要因为看到乱码就放弃读取或者猜测内容——那等于在没有情报的情况下做决策。

### 看到 `⚠️ 数据可能已过期`

这不是错误，是工具在尽职提醒。按上面「数据新鲜度」一节的第 1–3 步处理即可。
