# 数据字典

本文件解释 `self.json` / `others.json` / `world_overview.json` 里每个字段的含义。
键名固定为英文（程序稳定），值是简体中文（给人读）。

## 顶层结构

| 键 | 含义 |
|---|---|
| `kind` | 文档类型：`nation.self` / `nation.others` / `world.overview` / `world.index` |
| `文档类型` | 上面那个的中文说法 |
| `生成时间` | 本工具读取存档的 Unix 时间戳（不是游戏年份） |
| `world` | 世界名称、游戏年份、存档时间与新鲜度 |
| `knowledge` | 本文件的信息边界声明（哪些能确信、哪些只是估算） |

## identity 国家标识

| 键 | 含义 |
|---|---|
| `id` | 国家编号，全世界的唯一标识 |
| `名称` | 国名 |
| `格言` | 国家格言 |
| `种族` | 存档里的种族 id，如 `human`、`elf`、`orc` |
| `种族称呼` | 该种族在当前世界里的具体亚种名 |
| `国旗色号` / `国旗图标号` / `国旗背景号` | 拼出该国国旗的三个编号 |
| `建国年` | 建国时的世界时间 |
| `旧国名` | 曾经用过的名字 |

## ruler 统治者

| 键 | 含义 |
|---|---|
| `国王` / `国王id` | 现任国王的名字与编号 |
| `国王特质` | 形如 `[{"id": "wise", "label": "睿智"}]`，决定其行为倾向 |
| `国王健康` / `国王营养` / `国王幸福度` | 0–100 左右的状态值，偏低意味着国王可能出事 |
| `国王所在城市` | 国王当前驻跸的城市 |
| `国王击杀数` / `国王声望` | 个人战绩与人望 |
| `世代` | 角色在家族谱系中的世代（2=开国一代，3=第二代，以此类推） |
| `在位起始` | 当前国王开始统治的世界时间 |
| `王室宗族` / `王室宗族id` | 统治家族 |
| `历任国王数` | 该国历史上共有多少位国王 |
| `前任国王` | 最近的若干位国王及在位区间，用于看出王朝是否动荡 |

**注意**：存档不保存角色年龄，所以没有"国王多少岁"。频繁换国王
（`历任国王数`大、`前任国王`时间密集）通常意味着弑君或内战。

## status 国家状态

| 键 | 含义 |
|---|---|
| `是否存续` | `true` 表示至少还有一座城市；`false` 表示已亡国 |
| `声望` | 游戏中的国力/威望综合指标 |
| `声望排名` / `人口排名` | 在现存国家中的名次，1 为最强 |
| `国家特质` | 如 `经济强权`、`高额贡赋`、`爱好和平`——这些会实际影响国家行为 |
| `上次战争年` / `上次征服年` / `上次结盟年` | 最近一次此类事件的年份 |
| `迁出人数` / `迁入人数` / `向外迁徙` | 人口流动压力，迁出远大于迁入意味着民心不稳 |

## demographics 人口

| 键 | 含义 |
|---|---|
| `人口` | **常住人口**：归属该国的角色数，**不含船只**（沿海国家的船会被单独拿走） |
| `含船只条目数` | 上述人口 + 船只的存档条目总数。只有需要和原始存档条目数对齐时才用它 |
| `成年人口` / `儿童人口` | 来自游戏逐年统计的最后一年；无统计库时为 `null` |
| `船只` | 该国拥有的船只数量 |
| `患病` | 健康值处于危险区的人数 |
| `饥饿` | 营养值偏低的人数 |
| `平均幸福度` | 全部国民幸福度的平均值（约 -100 ~ 100） |
| `幸福度区间` | 最低与最高幸福度，用来看贫富/处境差距 |
| `职业分布` | 平民/士兵/战士等各有多少人 |
| `世代分布` | 各世代的国民数量，可看出是否经历过大灾变 |
| `金钱总量` / `人均金钱` | 由国民个人财产汇总，不是国库 |
| `累计出生` / `累计死亡` | 建国以来的总数 |
| `死因统计` | 战死、饿死、烧死等分类人数，能揭示这个国家经历了什么 |

## military 军事

| 键 | 含义 |
|---|---|
| `军队总兵力` | **在编军人数量**（士兵身上的军队标记统计得出） |
| `兵力占人口比` | 军队占人口的百分比，过高会拖垮经济 |
| `军队支数` | 有几支军队 |
| `累计击杀` | 建国以来该国造成的击杀总数 |
| `进行中的战争数` | 当前参与几场战争 |
| `军队明细` | 每支军队的番号、兵力、队长、驻地、战绩 |

判断"现在能打多少"用 `军队总兵力`；判断趋势用 `history` 里的 `army`。

## territory 领土

| 键 | 含义 |
|---|---|
| `城市数` | 拥有的城市数量 |
| `领土地块` | 所有城市所占地块数之和，可理解为国土面积 |
| `建筑总数` | 领土内的建筑数量 |
| `首都` / `首都id` | 首都名称与编号 |
| `城市列表` | 每座城市的详细情报 |

城市条目包含：`人口`、`其中士兵`、`领土地块`、`建筑数`、`房屋数`、
`无家可归`、`城市领袖`、`声望`、`累计击杀`、`累计死亡`、`建国年`、
`加入现王国年`、`语言`、`宗教`、`旧称`、`是否首都`。

看哪些城市是"顶梁柱"（人口大、建筑多），哪些是"负担"（无家可归多、
加入时间短、旧称频繁变化说明反复易主）。

## culture_and_faith 文化与信仰

| 键 | 含义 |
|---|---|
| `国家文化` / `国家语言` / `国家宗教` | 官方层面的文化、语言、宗教 |
| `境内使用的语言` | 治下各城市实际使用的语言，多于一种说明境内多民族 |
| `境内宗族` | 各宗族的击杀、死亡、声望与格言；强大的宗族是潜在的政治力量 |

## diplomacy 外交

| 键 | 含义 |
|---|---|
| `战争` | 正在进行的战争，含我方角色、敌人、双方阵亡数、爆发年份 |
| `对外关系` | 对每一个现存国家的关系：`交战` / `同盟` / `已接触` / `未知` |
| `盟友` / `敌人` | 由同盟与战争推导出的列表 |

`关系矩阵`（在 `others.json` 里）形如 `{"6|32": "war"}`，键是
`国家A|国家B`，值为 `war` 或 `alliance`。

## history 逐年历史

**这是本工具最有价值的部分。** 来自 `map_stats.s3db`，是游戏自己逐年记录的
统计，每个年份一行，字段缺失表示当年没统计到。

| 字段 | 含义 |
|---|---|
| `timestamp` | 游戏年份 |
| `population` / `adults` / `children` | 人口结构 |
| `army` / `boats` | 军队与船只 |
| `territory` / `buildings` / `cities` | 领土、建筑、城市数 |
| `food` / `money` | 粮食储备与国库 |
| `hungry` / `starving` | 饥饿 / 濒临饿死人数 |
| `happy` | 幸福度总和（要除以人口才是均值） |
| `homeless` / `housed` | 无家可归 / 有房人数 |
| `families` / `males` / `females` | 家庭与性别结构 |
| `kills` / `deaths` / `births` | 当年击杀、死亡、出生 |
| `renown` | 声望 |
| `joined` / `left` / `moved` / `migrated` | 加入、离开、迁入、对外迁徙 |
| `deaths_*` | 按死因分类的当年死亡人数 |

时间分辨率可选：`KingdomYearly1`（每年一行）、`KingdomYearly10`（每十年）、
`KingdomYearly100`（每百年）。看近期动向用 1，看长周期兴衰用 100。

> **两套时间刻度**：`world.年份`（如 212）是历史纪年，而 `history.timestamp`
> 与事件里的 `年份`（如 12468）是世界时间，起点不同。只在同一套刻度内部比较
> （事件之间比先后、历史行之间比趋势），不要跨刻度相减。

## recent_events 大事记

| 键 | 含义 |
|---|---|
| `年份` | 事件发生的游戏年份 |
| `事件` | 中文事件名，如 `新国王登基`、`城市被攻占`、`国王被杀` |
| `事件码` | 存档里的英文事件 id，便于精确比对 |
| `主角` / `对象` / `补充` | 事件的参与者（通常是人名或城名） |
| `坐标` | 事发地点在地图上的坐标 |

## others.json 列国简报

| 键 | 含义 |
|---|---|
| `viewpoint_kingdom_id` | 站在哪个国家的视角 |
| `列国` | 每个他国的核心指标：人口、城市数、军队兵力、声望、击杀、国家特质 |
| `我方立场` / `我方立场码` | 对你而言是 `敌对` / `盟友` / `中立` |
| `其参与的战争` | 该国正在打的战争 |
| `正在进行的战争` | 全世界所有战争及双方 |
| `关系矩阵` | 谁在打谁、谁和谁同盟 |
| `同盟` | 所有同盟及其成员 |

**做任何外交或军事决定前都应该先读这个文件。**

## world_overview.json 世界概览

| 键 | 含义 |
|---|---|
| `world` | 世界名称、地图尺寸、年份、纪元、世界法则、启用的模组 |
| `totals` | 各国数量、城市、人口、战争、文化、语言、宗教、累计死亡与死因分布 |
| `国力排行` | 所有现存国家的横向对比，按国力排序 |
| `进行中的战争` | 全世界所有战争 |
| `世界逐年统计` | 世界层面的逐年数据（总人口、城市数、战争数等） |
| `全局事件记录` | 全世界的事件流水 |

## 口径与已知限制

**已验证的口径**（对照本机真实存档逐一核对过）：

- 人口 = 存档中 `civ_kingdom_id` 归属该国的角色数，**不含船只**
  （`含船只条目数` 是加上船只后的原始条目数）。
  所有文档的「人口」都用这一个口径：`self.json`、`others.json`、`_index.json`、
  `world_overview.json` 的人口可以互相直接比较。
- 军队 = 上述角色中带军队标记的数量
- 领土 = 该国各城市所占地块数之和
- 建筑 = 存档中 `cityID` 属于该国城市的建筑条目数

**同一个名字、两个不同时间点的数值**（不是错误，是时点不同）：

| 指标 | 即时值（最新存档） | 历史值（逐年统计） |
|---|---|---|
| 人口 | `demographics.人口` | `history[].population` |
| 军队 | `military.军队总兵力` | `history[].army` |
| 声望 | `status.声望` | `history[].renown` |

游戏每年年初记录一次统计值，而即时值反映当前存档时刻的实况。两者都真实。
**判断"现在能打多少、现在多强"用即时值；判断"在变强还是变弱"用 `history`。**
`self.json` 的 `knowledge.口径歧义提示` 会把当前国家的两套数字同时列出来。

**限制**：

1. **没有角色年龄**。存档不写入年龄字段，所以本工具不提供。
2. **粮食、国库、忠诚度只在 `history` 里**，城市记录本身不保存这些。
3. **忠诚度字段在存档中为空**，因此不提供——不要从别处推测。
4. **成年/儿童人口来自逐年统计**（每年记一次），因此是最新年份的值，
   可能和即时人口有小差异。
5. **军队与声望的即时值和逐年统计值会有出入**，因为统计是每年年初记录的，
   而即时值反映当前存档时刻。两者都真实，只是时间点不同。
6. **多国家同名时**按名称查询会返回其中一个（取更强大者），精确查询请用编号。
7. **数据延迟约 0–5 分钟**，取决于游戏何时自动存档。请始终检查
   `world.存档距今秒数`，超过 600 秒时文档里会出现 `_警告` 字段，
   `wb.py` 也会在 stderr 上主动提示。
8. **`totals.累计建立王国_游戏计数器` 可能小于现存王国数**——这是游戏统计本身
   在该世界里出现的反常值（可能受模组影响），仅供参考，不要据此推断历史。
