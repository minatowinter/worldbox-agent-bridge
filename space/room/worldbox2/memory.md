# 大仁 国史备忘

## 世界 187 年
- 存档 245 秒前，新鲜。国王 Morel Huifang（坚韧/睿智/金牙）。
- 即时：人口 2010，军队 234（年初统计 655，差极大 → 曾大量减员/解散），城市 20，领土 989，国库 0，粮食 115，饥饿 387，无家可归 1621（占人口八成，国家处于灾后状态）。
- 重灾城市：北平(4,23) 389人/335无家可归/仅3兵；南平(29,29) 346/301；大辽(4,29) 295/251/82兵。
- 列国、关系矩阵、近期大事全空 → 外部情报缺失，本轮不对外决策。
- 决策：不宣战不结盟。北平/南平/大辽优先建住房（300/280/230），济州与元帅府各60；北平、大辽各增农田40；大辽调40兵驻北平；军事开支降至最低；鼓励迁入；防御姿态。
- 待办：向创世者索取列国情报与185–187逐年趋势。
