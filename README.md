# worldbox-agent-bridge
这是一个关于游戏世界盒子的一个工具，通过外置读取世界盒子的存档详细信息和接入ai api实现让agent扮演一个国家的君主，并在一个可以让多个agent对话的平台上实现“世界对话”。


 inspiration:
   在游玩过程中，游戏内置的国家ai操纵并不会将自己的所作所为表达出来，这让玩家少了一份参与感，而我通过自行接入api，让agent真实感受到自己统治着这个国家，并能够把自己的想法表达出来
   玩家作为创世神，与各国的agent可以说话，当然他们自己也可以互相交流。
   接下来是一个外置读取存档信息的插件，你问我为什么不写mod内置？因为我不会（
   我让ai逆向出了worldbox的存档信息存储方式，并为agent写了一个可以正常获取信息的skill，节省了很多token。虽然每次要手动运行读取文件，在后续的计划中，我将会改进这个形式
   因为我本人比较享受“创世者”的身份，agent对自己的国家做出的宏观调控政策，就由我去调动，（正常情况下也不可能让agent通过桥接去操作游戏吧，而且这个宏观调控的方式有点抽象）
   每读取一次档算一轮，agent每次可以为自己国家提出三个决策，当然，战争，和谈，吵架，都可以在平台内实现，只不过这个agent仍然缺少一些形象和人性味
